# Atelier

Настольное приложение для Windows x64: Item Crafting, Map Crafting, Unique Crafting и Harvest Crafting.

Первый выпуск с установщиком готовится. После публикации его можно будет скачать в разделе [Releases](https://github.com/Koshey-spb/POE_Atelier/releases).

Приложение поддерживает проверку обновлений через стабильные выпуски этого репозитория; установка обновления запускается пользователем и требует перезапуска.

Профили, настройки и журналы хранятся отдельно в `%LOCALAPPDATA%\Atelier`. Отправленные команды не подтверждают фактический расход игровой валюты.
